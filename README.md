# PoclerSearch 4.0

Buscador web estático, adaptable a móviles, con un botón destacado para abrir PoclerVideo.

## Publicar en GitHub Pages

1. Descarga y descomprime este ZIP.
2. Abre el repositorio de GitHub `poclersearch3.0`.
3. Sube `index.html`, `style.css`, `app.js` y `README.md` a la raíz del repositorio, sustituyendo los archivos antiguos.
4. Confirma los cambios con **Commit changes**.
5. Espera uno o dos minutos y abre:
   https://cesarviro-coder.github.io/poclersearch3.0/

## Categorías

- **Páginas:** busca artículos de Wikipedia.
- **Imágenes:** busca archivos de Wikimedia Commons.
- **Vídeos:** intenta localizar archivos de vídeo en Wikimedia Commons.
- **Noticias:** consulta artículos recientes mediante la API pública de GDELT.

## Importante

- No redirige a DuckDuckGo.
- El botón **Abrir PoclerVideo** apunta a https://cesarviro-coder.github.io/poclervideo/
- Este proyecto es un buscador pequeño que consulta fuentes públicas; no es un índice independiente de toda Internet.
- Los servicios externos pueden limitar solicitudes o no responder temporalmente.
